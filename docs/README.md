# Website Promosi MASAJIDALLOH PRO (GitHub Pages)

Website statis berisi pengenalan platform, ilustrasi desain dashboard, rancangan paket, dan alur onboarding. Tidak mengumpulkan data pribadi, tidak menerima pembayaran, tidak mempunyai login backend, dan tidak menampilkan data asli tenant.

## Cara mengaktifkan publikasi

1. Buka Settings → Pages repo `markazdakwahdigital/Masajidalloh-Pro`.
2. Source: **Deploy from a branch**.
3. Branch: **main**; folder **/docs**; Save.
4. Setelah GitHub Pages menyatakan live, alamat standar: `https://markazdakwahdigital.github.io/Masajidalloh-Pro/`. Jangan menyatakan URL live sebelum diuji.

Pengaturan GitHub Pages terpisah dari deployment Next.js ke Netlify (yang sedang dibatasi kredit). Halaman ini hanya materi promosi, bukan pengganti backend SaaS. Perbarui link publikasi apabila menggunakan custom domain.
