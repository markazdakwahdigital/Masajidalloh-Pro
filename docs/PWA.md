# PWA MASAJIDALLOH PRO

Manifest, service worker, dan halaman offline tersedia. Dashboard dan data pribadi tidak disimpan di cache.

Sumber logo: public/brand/logo.webp, raster teroptimasi dari gambar unggahan pengguna. Ikon instalasi dibuat oleh scripts/generate-brand-icons.mjs sebelum build.

Catatan: sumber raster sementara dibatasi resolusinya untuk transfer melalui integrasi. Logo master resolusi penuh tetap perlu dipakai saat finalisasi branding agar ikon dan header setajam gambar asli.

Instalasi: Android Chrome/Edge menggunakan menu Install app; iPhone/iPad Safari melalui Share > Add to Home Screen; desktop Chrome/Edge via menu instalasi. Verifikasi dengan perangkat asli.

Official full-quality user logo was restored into /brand/logo.webp, and compact PWA icons focus on the mosque crest to remain sharp at small sizes. Update icons through npm run build; source is not a recreated logo.
