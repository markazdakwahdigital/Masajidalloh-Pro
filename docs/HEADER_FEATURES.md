# Header operasional MASAJIDALLOH PRO
- Pencarian hanya untuk menu/masjid/kegiatan yang benar-benar terlihat sesuai izin pengguna; tidak memeriksa data tenant lain.
- Tanggal Masehi dan Hijriah dari Intl dengan kalender Umm al-Qura; hasil Hijriah adalah perhitungan dan dapat berbeda dari ketetapan Kemenag.
- Jadwal salat harus memilih kota, tidak boleh mengasumsikan lokasi semua masjid sama. Sumber: AlAdhan API Kemenag metode 20; wilayah dan akurasi wajib diperiksa dengan jadwal lokal.
- Area profil menampilkan nama pengguna sesuai role yang terverifikasi; identitas Ketua DKM dan foto belum disimpan dalam skema, sehingga placeholder yang jujur harus dipertahankan.
- Foto asli orang tidak boleh ditampilkan tanpa input atau data tepercaya. Penambahan field peran ketua DKM dan unggah avatar perlu izin hak akses dan kebijakan penyimpanan.
